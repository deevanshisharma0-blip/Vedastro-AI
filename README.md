# Dropshipping Brand OS — Phone App

This repo holds the React Native / Expo phone app (.apk) for the Dropshipping Brand OS.

The app is the founder's control panel: monitor every agent, approve every public action, track revenue and disputes in real time.

**Primary repo (engine + agents):** `deevanshisharma0-blip/autoagents`

## App Modules (built in Phase 6)
1. Home / Command Center
2. Live Activity Feed
3. Decisions (approval queue — the hard gate)
4. Agents (org chart + status)
5. Products
6. Orders
7. Finance
8. Marketing
9. Customer Service
10. Settings / Health
